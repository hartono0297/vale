The app

At your own risk

These features change files, settings or the system. You use them at your own risk, so keep backups of anything you cannot replace.

  • The cleaner. It has 7 categories. It deletes caches, temporary files and logs permanently. It moves old installers to the Recycle Bin. It removes Windows Update leftovers through a helper that asks for administrator rights, and you approve that in the UAC prompt. Nothing is deleted until you click the confirm button.
  • Mole mode. This runs your own copy of Mole, which Vale never installs. Vale does a dry run first. If you add the system part, it runs with administrator rights, and you approve that in the UAC prompt.
  • The CLI. It runs any command you type, in PowerShell or cmd. Vale does not check what the command does.
  • Eject. It sends a safe-removal request to Windows. Windows can refuse it.
  • Screenshots. Saving writes image files to your Windows Screenshots folder, which is %USERPROFILE%\Pictures\Screenshots by default. Deleting one from the preview moves the file to the Recycle Bin and also takes the picture off your clipboard, if it is still there, and out of the clipboard history unless you pinned it. Copying it again puts it back on the clipboard. If you set If ignored to Delete in Settings, a screenshot you leave alone is moved to the Recycle Bin when its preview closes, and taken off the clipboard the same way. That file can be one that Snipping Tool saved, not Vale. The default is Keep.
  • Volume. The Mixer and the mouse wheel over the notch change your volume.
  • Autostart. Vale starts with Windows by default. You can turn this off in Settings.
  • Claude Code hooks. Installing them edits %USERPROFILE%\.claude\settings.json. Vale first saves a backup as settings.json.bak-vale.
  • Shortcut tiles. They launch apps, folders and URLs, and they can lock your PC.
