# Landing page for Vale 5.6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring `site/` (the "Night mix" landing page) up to Vale 5.6: three switchable mascots and notch colours in the hero and the live notch, Record as the 15th page, an eight-card playground with signing, rotation, captions and the phone link, and current install and privacy copy.

**Architecture:** Edit the existing static site in place (`site/index.html`, `site/style.css`, `site/site.js`, `site/privacy.html`); no build step, no library. Mascot and notch-colour choice live as attributes on `<html>` (`data-mascot`, `data-notch-style`) plus CSS custom properties, so CSS does the switching and JS only sets state. `scripts/check-site.py` is the committed test gate and gets each new expectation before the markup it checks.

**Tech Stack:** HTML, CSS, vanilla ES5-style JS (the file's style: `var`, `function`, IIFE), Python 3 stdlib checker.

**Spec:** `docs/superpowers/specs/2026-11-21-landing-v5-design.md`. Background every task must read first: `docs/memory/site-landing.md` (how the site works, tokens, measured contrast, the story pin, the notch states, the shared markup contract).

## Global Constraints

- No em dash (U+2014) anywhere under `site/`; sentence case; no eyebrow labels, no arrows on buttons, no numbers, testimonials or claims that are not in `README.md`, `docs/guide.md` or `src/whats_new.rs`.
- No third-party request, no new font, no library. Local Geist / Geist Mono only.
- Dark is the default theme; every new colour gets a light-theme value under `:root[data-theme="light"]` (the notch and the dark "screens" stay the same in both themes, as today).
- Text contrast WCAG AA (4.5:1, 3:1 for large text); controls and indicators 3:1. Compute it, never eyeball it (`python C:/Users/Hartono/.claude/plugins/cache/anti-slop/antislop/3.2.23/skills/antislop-human/contrast-check.py "#fg" "#bg"`).
- Every control is a real `button`/`a`, at least 44 x 44 px, keyboard reachable, with the site's 3 px terracotta focus ring. Toggle groups use `aria-pressed`.
- Reduced motion (`prefers-reduced-motion: reduce`): no jumps, loops or scripted motion; state changes are instant.
- Without script: pickers and card controls are hidden (`.js-only`), everything else reads; the notch is Plain with the cat.
- Storage only through the existing `store()` helper and try/catch reads; keys `vale-mascot`, `vale-coat-cat`, `vale-coat-falk`, `vale-coat-octo`, `vale-notch-style`. Missing or blocked storage means Cat, Terracotta, Plain.
- Colours (spec, verbatim): Lutino body #F1E4A2 face #F6D04A crest #F6D04A cheeks #EC6B3A; Grey body #9A959C face #F2D35A crest #E9CF62 cheeks #EC6B3A; White face body #9A959C face #F4EFE6 crest #E4DED6 no cheeks; beak #D9978F; octopus Coral #E87C8E, Red #D9505F, Purple #A98BD6, Sea blue #5FA8C9, spots the body mixed 18 % toward black. Notch tints: Terracotta and Calico #E2683C, White #F6F1EA, Black #8E7CB8, Lutino #F6D04A, Grey and White face #9A959C, octopus its body colour.
- Shapes for the cockatiel and octopus: the 64-grid paths in `docs/design/maskot-pilihan-akhir.html` (`FALK`, `CREST` via `feather()`, `MANTLE`, the arms in `octo()`), scaled by 4 into the site's 256 grid.
- The cat-only extras stay cat-only and keep the cat's coat whatever mascot is picked: the wish and its constellation, the walking cat, the go-to-top tail, the story screen's cat.
- Every subagent loads the antislop skills before writing UI or copy (`antislop:antislop`, `antislop:antislop-ui`, `antislop:antislop-layoutmobile`, `antislop:antislop-human`, `antislop:antislop-copywriting` for copy) and runs their checklists on its own diff.
- Do not commit `AGENTS.md`; do not touch `docs/design/rak-hp.html` or `docs/design/screens/`.
- Verify in the browser pane by serving `site/` with `python -m http.server 8765 --directory site` (add a `.claude/launch.json` entry `site` if missing; do not commit it) and opening `http://localhost:8765/`.
