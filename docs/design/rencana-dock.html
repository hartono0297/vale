Dock ala macOS yang menggantikan taskbar Windows

Bar app di tepi bawah layar: app yang di-pin dan yang sedang jalan, ikon yang membesar saat di-hover, titik untuk app aktif, auto-hide, dan Launchpad dari tombol Start. Pada akhirnya taskbar Windows disembunyikan, lalu Vale menyediakan sendiri Start, status (jam, volume, wifi, baterai, notifikasi) dan akses ke tray. Dock ini berbeda dari "dock" titik halaman di panel notch (src/ui/dock.rs); rumus pembesarannya dipakai ulang.

Preview live di atas Chrome, Figma sedang loncat, Discord dengan badge 12.

Aturan umum
  • Semua gerak berjalan di FrameClock yang sudah ada dan berhenti begitu diam. Tidak ada timer yang jalan terus (lihat bata-idle-power-budget).
  • Mouse hanya mengatur target. Nilai yang tampil mengejar target lewat v += (t - v)(1 - e^(-dt/τ)), tanpa overshoot dan tidak bergantung frame rate (sama dengan dock halaman).
  • Reduced motion, Energy Saver, atau animasi Windows mati: semuanya langsung lompat ke nilai akhir. Loncat dan poof diganti fade pendek.
  • Target 60 fps dengan refresh tinggi diikuti. Jendela Dock hanya selebar Dock saat membesar, tidak selebar layar, supaya biaya UpdateLayeredWindow per frame tetap kecil. Fase 1c mengukur ini; kalau masih berat, pakai DirectComposition.
GerakSpesifikasi
PembesaranFalloff cosinus dengan jangkauan 2,5 lebar ikon, puncak default 1,8× (slider 1,0–2,2), τ 70 ms. Ikon tumbuh dari tepi bawah. Lebar Dock = jumlah lebar ikon yang sudah dibesarkan, jadi tetangga bergeser mulus seperti Mac. Klik memakai layout diam sehingga target tidak goyang.
Muncul / sembunyiKursor diam di tepi bawah selama 150 ms → naik 240 ms ease-out cubic. Kursor keluar dari Dock → tunggu 500 ms, lalu turun 200 ms ease-in. Menu, preview, atau drag yang terbuka menahan Dock.
LoncatSiklus 600 ms: naik 18 dip (ease-out), turun (ease-in), lalu satu pantulan kecil 7 dip. Berulang sampai jendela app muncul atau 5 detik lewat. App yang minta perhatian (flash) loncat 3×.
TitikFade-in 150 ms saat app jalan, fade-out 200 ms saat app keluar. App yang tidak di-pin menyusut keluar dalam 220 ms dan tetangganya bergeser rapat.
Urutan (drag)Ghost ikon mengikuti kursor; tetangga membuka celah dalam 180 ms. Drag lebih dari 48 dip ke atas Dock memunculkan label "Lepas"; dilepas → animasi poof 250 ms (5 bingkai awan) dan tetangga merapat.
PreviewHover diam 400 ms → kartu thumbnail fade + naik 6 dip dalam 150 ms. Pindah ke ikon lain saat preview terbuka berganti langsung tanpa jeda. Thumbnail memakai DwmRegisterThumbnail, jadi live dan tanpa salin piksel.
TumpukanGrid file terbaru tumbuh dari ikonnya: 200 ms scale 0,9→1 + fade. Klik file untuk membuka, atau drag keluar.
BadgeMuncul dengan scale 0,6→1 dalam 180 ms; angka berganti dengan crossfade.
LaunchpadBuka: zoom 1,06→1 + fade 220 ms di atas scrim permukaan 85%. Tutup: kebalikannya dalam 180 ms. Geser halaman memakai pegas τ 90 ms dengan rubber band di ujung. Folder terbuka melebar dari ikonnya dalam 200 ms.
MinimizeEfek genie Mac tidak bisa dibuat untuk jendela app lain. Windows tetap memakai animasi minimize miliknya; sisa ruang di sini sengaja dibiarkan.

Yang dipakai ulang
  • ui/dock.rs: falloff, smoothing, dan hit-test yang tidak goyang
  • arrange_win.rs: enumerasi jendela, pemindah jendela, Susun dari menu klik kanan
  • search_details.rs / search.rs: ikon dan daftar app untuk Launchpad
  • notch_monitor.rs: pilihan monitor dan hot-plug (DBT_DEVNODES_CHANGED)
  • sources/fullscreen.rs: deteksi fullscreen per monitor; Dock menambah pembedaan D3D exclusive
  • app_hotkeys.rs + hook PrtSc: tempat menangkap tombol Win
  • Riwayat notifikasi: angka badge per app
  • shelf: drop target OLE untuk "taruh file ke ikon"
  • Tema, permukaan, tembus pandang, dan font dari Settings Tampilan
Tombol Win. Win ditekan lalu dilepas tanpa tombol lain → Launchpad. Hook menelan Win dan menyuntik tombol dummy supaya Start Windows tidak ikut terbuka. Win+X, Win+E, dan kombinasi lain tetap lolos. Kalau hook mati, Win kembali membuka Start Windows. Ini masuk Spike.
Hemat daya. Diam = nol timer dan nol frame. Event jendela memakai hook out-of-context. Ikon dibuat sekali lalu di-cache. Thumbnail DWM tidak menyalin piksel. Ukuran exe diukur setiap fase (catatan exe-size).

Risiko dan Spike

Yang harus dibuktikan dulu, dan cek manual

5 pertanyaan Spike (Fase 0)
  • Sembunyikan taskbar di Windows 11 26200. Apakah ShowWindow(Shell_TrayWnd, SW_HIDE) + auto-hide bertahan saat Win ditekan, saat Start atau Search terbuka, dan saat tablet mode? Apakah area kerja ikut terbebas?
  • Pulih. Setelah Explorer restart (TaskbarCreated), sleep/resume, dan Vale dibunuh paksa, apa yang terjadi? Taskbar harus selalu bisa kembali, dan Vale butuh penanda "taskbar disembunyikan oleh Vale" untuk dipulihkan di start berikutnya.
  • Flyout tray. Bisakah overflow tray asli dibuka saat taskbar tersembunyi (Win+B, NotifyIconOverflowWindow, atau munculkan taskbar 5 detik)? Bagaimana posisinya?
  • Tombol Win. Tangkap Win yang ditekan sendirian tanpa Start ikut terbuka dan tanpa merusak Win+kombinasi, termasuk di layar kunci dan UAC.
  • Tepi saat fullscreen. Di video borderless dan game D3D exclusive, apakah jendela topmost yang muncul membuat game minimize atau stutter?
Risiko terbesar: layar tanpa taskbar dan tanpa Dock setelah crash. Aturannya keras: setiap jalur keluar mengembalikan taskbar; start berikutnya memeriksa penanda; menu tray dan Settings punya "Kembalikan taskbar Windows"; dan ada perintah vale.exe --restore-taskbar.
Cek manual awal (diperluas tiap fase)
  • Hover sepanjang Dock: pembesaran mulus, tidak goyang, tetangga bergeser rapi; diam = CPU ~0 %
  • Buka dan tutup app: titik muncul dan hilang, app yang tidak di-pin masuk dan keluar dengan animasi
  • Klik app aktif → minimize; klik lagi → kembali; app dengan 2 jendela → berputar
  • Sembunyi otomatis: tepi bawah memunculkan, keluar menyembunyikan; menu dan preview menahan Dock
  • Fullscreen video vs game: perilaku sesuai keputusan
  • Ganti monitor notch / cabut monitor: Dock ikut pindah
  • Gelap/terang, warna sendiri, tembus pandang
  • Fase 2: bunuh Vale dari Task Manager → taskbar kembali (langsung, atau paling lambat di start berikutnya)
  • Fase 2: restart Explorer → taskbar tetap tersembunyi, Dock tetap ada
  • Fase 3: tombol Win membuka Launchpad; Win+E tetap membuka Explorer
Di luar rencana (sengaja): efek genie minimize, widget di Dock, Dock vertikal sebelum Fase 5, tray buatan Vale sendiri (terlalu rapuh).
