GambarPilih file (PNG, JPG, GIF, BMP, WebP)–
  • Dengan seleksi: klik mengubah seleksi (kalau semuanya sudah tebal, klik melepasnya). Tanpa seleksi: gaya berlaku untuk huruf yang diketik berikutnya, seperti Word.
  • Tombol menyala sesuai gaya di caret / seleksi. Tooltip dengan pintasan saat hover.
  • Toolbar tidak menggeser teks: tinggi 42 dip menggantikan footer 26 dip, area teks sedikit mengecil saat mengetik.

Gambar

  • Tiga cara: tombol gambar (pilih file), Ctrl+V gambar dari clipboard (mis. screenshot), seret file gambar ke catatan. File bukan gambar tetap jadi baris path seperti sekarang.
  • Tampil di atas teks: 1 gambar selebar catatan (tinggi maks 45% catatan, dipotong rapi), 2 berdampingan, 3–4 jadi kisi 2×2. Maks 4 gambar per catatan.
  • Hover: ✕ untuk hapus (bisa Ctrl+Z selama masih mengedit), klik gambar membuka di aplikasi foto Windows.
  • Disimpan sebagai salinan di folder data Vale (note-images\), diperkecil ke sisi terpanjang 1600 px. File asal maks 25 MB; lebih besar ditolak dengan pesan di footer. Hapus catatan = hapus gambarnya.
  • Catatan digulung: gambar tidak tampil. Tumpukan, selip ke tepi, tembus pandang: tetap berlaku.

Penyimpanan & catatan lama

  • Teks tetap plain text di notes.json. Format disimpan sebagai daftar rentang di bagian sticky (tebal 3..8, stabilo kuning 12..19, dst), gambar sebagai daftar nama file. Butir list ditulis • di awal baris, jadi terbaca di mana saja.
  • Catatan lama tidak perlu migrasi: tanpa rentang = tanpa format. File lama dibaca dan disimpan balik tanpa kunci baru.
  • Saat teks berubah (dari catatan, halaman Notes, atau drop), rentang digeser otomatis; yang terhapus ikut hilang.

Copy-paste, halaman Notes, HP

  • Copy dari catatan: clipboard berisi teks biasa (untuk aplikasi lain) dan format Vale sendiri. Paste ke catatan Vale lain = format ikut.
  • Paste dari luar: teks biasa, mengikuti gaya di caret (tidak membawa font/warna aneh dari web).
  • Halaman Notes di panel: tetap teks biasa (butir • terlihat), mengedit di sana menjaga format di bagian yang tidak diubah. Kartu catatan bergambar dapat ikon gambar kecil + jumlah.
  • Kirim ke HP: halaman HP menampilkan tebal, miring, garis bawah, coret, stabilo, warna, dan butir. Gambar tidak ikut dikirim.
